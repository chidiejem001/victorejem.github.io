PUBLISHING STEPS:
1. Sign in to GitHub and verify your email.
2. Create a PUBLIC repository named exactly YOUR-GITHUB-USERNAME.github.io (replace with your actual username).
3. Unzip this package on your computer.
4. In the repository, choose Add file > Upload files.
5. Upload index.html and style.css (upload the files themselves, not the enclosing folder).
6. Click Commit changes.
7. Open Settings > Pages.
8. Under Build and deployment, select Deploy from a branch. Select branch main and folder /(root), then Save.
9. Wait a few minutes and visit https://YOUR-GITHUB-USERNAME.github.io

Official guide: https://docs.github.com/en/pages/quickstart
